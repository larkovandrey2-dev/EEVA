# EEVA: Гибридная система рекомендаций для ПСБ

> Переход от агрессивных продаж к закрытию моментальных потребностей клиента.

## Концепция: Reactive Banking
Вместо анализа тяжелых исторических данных за годы, которые часто создают шум, мы сделали ставку на **Instant Needs (Мгновенные потребности)**. Система реагирует на контекст и последние действия пользователя, предлагая то, что нужно ему *здесь и сейчас*.

## Архитектура решения
Мы не используем "черный ящик". Наше решение — это ансамбль из 4 интерпретируемых модулей:

1.  **Static Layer (Профиль):** GMM кластеризация + Twin Matcher. Определяет архетип клиента (Студент, VIP, ОПК) даже для новых пользователей (Cold Start) через поиск цифровых двойников.
2.  **Dynamic Layer (Паттерны):** Цепи Маркова (Markov Chains). Предсказывают следующий вероятный шаг на основе последней транзакции.
3.  **Rule Layer (Бизнес-логика):** Hard-фильтры. Система управления рисками (не предлагаем инвестиции закредитованным) и проверка совместимости продуктов.
4.  **Generative Layer (Коммуникация):** YandexGPT. Генерирует уникальные, нешаблонные маркетинговые сообщения под каждый сегмент.

## Ключевые особенности MVP
*   **Специфика ПСБ:** Реализована поддержка приоритетных сегментов (ОПК/Силовые структуры) с выдачей профильных продуктов (карта «Сильные люди», военная ипотека).
*   **Risk Management:** Автоматическая блокировка рисковых продуктов для сегмента `Credit Optimization`.
*   **Smart Fallback:** Система отказоустойчива — при ошибках данных или API бесшовно переключается на безопасные базовые стратегии.
*   **High Performance:** Оптимизированная работа с данными через `Parquet` (память O(1)).

## Технический стек
*   **Core:** Python 3.11, Pandas, NumPy
*   **ML:** Scikit-learn, Custom Markov Chain implementation
*   **Data Storage:** Fast Parquet
*   **LLM:** YandexGPT API (Yandex Cloud)
*   **Frontend:** Streamlit (Custom CSS/HTML injection)
